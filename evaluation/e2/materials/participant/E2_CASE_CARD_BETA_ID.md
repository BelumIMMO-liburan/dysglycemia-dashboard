# Kartu Kasus Penelitian: Case Beta
## Profil Data Skrining Fiktif Tahap-1

**Kode Kasus:** `CASE-BETA`  
**Peruntukan:** Materi Peserta (Tugas 4 dan Tugas 6)  
**Sifat Data:** Fiktif / Sintetis untuk Keperluan Penelitian  

---

### Parameter Input Skrining (Canonical Seven Predictors)

| No | Parameter Kesehatan | Nilai Input untuk Formulir | Keterangan Pilihan pada Antarmuka |
| :-: | :--- | :--- | :--- |
| 1 | **Usia (Age)** | **32** tahun | Masukkan angka `32` |
| 2 | **Jenis Kelamin Biologis (Sex)** | **Perempuan (Female)** | Pilih opsi `Female` |
| 3 | **Indeks Massa Tubuh (BMI)** | **23.5** kg/m² | Masukkan angka `23.5` |
| 4 | **Riwayat Hipertensi (Hypertension)** | **Tidak (No)** | Pilih opsi `No` (Tidak pernah didiagnosis hipertensi) |
| 5 | **Riwayat Merokok (Smoking)** | **Ya (Yes)** | Pilih opsi `Yes` (Pernah merokok $\ge 100$ batang seumur hidup) |
| 6 | **Lingkar Pinggang (Waist Circumference)** | **74.0** cm | Masukkan angka `74.0` |
| 7 | **Waktu Sedentari Harian (Sedentary Time)** | **300** menit/hari | Masukkan angka `300` (setara 5 jam/hari) |

---

*Catatan untuk Peserta:*  
Masukkan ketujuh parameter di atas secara teliti ke dalam menu **New Screening**. Setelah formulir terisi lengkap, klik **Review Inputs**, lalu jalankan skrining dengan menekan **Run Screening**.
